# 錦鯉アプリ
日本の伝統文化である「錦鯉」の美しさとその奥深さを、3D空間で体験・継承できるシミュレーターです。
単なる育成ゲームではなく、錦鯉の持つ「生きた芸術」としての美しさの再現と、その文化的な背景を体験することにフォーカスしています。

### 主な機能
- **交配**
  - 錦鯉特有の美しい模様や色彩の遺伝をシミュレートし、自分だけの美しい一匹を追い求めることができます。
- **飼育 (未実装)**
  - 美しい水面シェーダーと心地よい環境の中で、錦鯉が優雅に成長する姿をのんびりと眺めることができます（スローライフ・癒やし要素）。
- **品評会 (未実装)**
  - 育て上げた錦鯉の「美しさ」を評価し、競い合う伝統的な品評会文化をアプリ内で擬似体験できます。

### 使用技術
- **開発エンジン**: Unity 
- **開発言語**: C#
- **グラフィック / パイプライン**: URP (Universal Render Pipeline) 
- **その他**: Git (CLIによるバージョン管理)
