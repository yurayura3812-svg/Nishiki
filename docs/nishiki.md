# 錦鯉アプリ 仕様書

## 1. アプリ概要

### 1.1 アプリ名
錦-NISHIKI-

### 1.2 開発目的
錦鯉は、日本の伝統文化の一つであり、個体ごとに異なる模様や色彩、質感が魅力となっている。また、交配によって新たな特徴を持つ個体が生み出され、品評会ではその模様や体型、艶などが評価されるという、独自の文化が形成されている。

一方で、実際に錦鯉を飼育するには池や設備などの環境が必要となるため、交配や品評会といった文化に触れる機会は限られている。

そこで本アプリでは、デジタル技術を活用し、錦鯉の模様や質感の違いを楽しむとともに、交配によって新たな模様の個体を生み出す体験を提供する。さらに、品評会を通じて錦鯉の評価の観点にも触れられるようにする。

これらの体験を通じて、錦鯉をより身近に感じてもらい、その魅力や日本の伝統文化への関心を高めることを目的とする。

### 1.3 コンセプト
**交配で広がる錦鯉の個性を楽しみ、デジタルを通じて日本の伝統文化に触れる。**

錦鯉の模様や質感の違いを観察し、交配によって新たな個体を生み出すことで、一匹ごとの個性を楽しめる体験を提供する。また、品評会を通じて錦鯉の評価方法にも触れ、見た目を楽しむだけでなく、錦鯉文化への理解を深めることを目指す。

### 1.4 対象ユーザー
- 錦鯉に興味があり、模様や品種の違いを楽しみたい人
- 日本の伝統文化に興味がある人
- 交配による模様の変化や個体ごとの違いに関心がある人
- 実際に錦鯉を飼育することは難しいが、錦鯉に触れてみたい人
- 日本の文化や錦鯉の魅力を知りたい海外の人

### 1.5 アプリの主な特徴
- **模様や質感の鑑賞：** 3Dモデルを通じて、錦鯉ごとの模様や艶の違いを楽しめる。
- **交配による個体の創出：** 錦鯉同士を交配させることで、新たな模様や特徴を持つ個体を生み出せる。
- **エサやりによる艶の変化：** エサやりを通じて錦鯉の艶を高め、見た目の変化を楽しめる。
- **品評会への参加：** 模様・体型・艶という観点から錦鯉を評価し、品評会の文化に触れられる。
- **個体ごとの個性の発見：** 交配によって生まれる違いを比較しながら、自分だけの錦鯉を楽しめる。

## 4. 機能詳細仕様

### 4.1 起動・池画面の入口
- **目的：** 起動直後に池を表示し、鑑賞しながら他機能へ移動できるようにする。
- **起動：** アプリ起動時は専用ホームを出さず、SCR-01（池の錦鯉画面）を表示する。
- **入力：** 池画面上のボタン操作。
- **処理：** 選択された機能に対応する画面（一覧・交配、品評会、池カスタム）を表示する。
- **出力：** 選択した画面を表示する。
- **詳細ルール：** 各機能への入口は池画面の UI に置く。

### 4.2 錦鯉の配置・鑑賞機能
- **目的：** 所持している錦鯉から好きな個体を選択し、池に泳がせて鑑賞できるようにする。
- **入力：** ユーザーが選択した錦鯉。
- **処理：** 選択された錦鯉を池に配置し、池の中で泳ぐように表示する。
- **出力：** 選択した錦鯉が泳ぐ池の画面を表示する。
- **操作：** 錦鯉一覧から個体を選択し、池に配置する。
- **詳細ルール：** （配置できる匹数、配置の解除・入れ替え方法などを記載する）

### 4.3 錦鯉一覧・詳細機能
- **目的：** 所持している錦鯉と個体ごとの特徴を確認できるようにする。
- **画面：** SCR-02（錦鯉一覧・交配画面）。交配機能（4.5）と同一画面とする。
- **表示項目：** 画像、個体ID、品種、模様、質感など。親選択スロット、交配操作、生成個体の表示も同じ画面に置く。
- **操作：** 一覧から個体を選択し、詳細を同画面内に表示する。詳細確認のあと、その個体を交配の親に割り当てられるようにする。
- **詳細ルール：** 一覧の更新は交配で子が保存されたタイミングでも行う。

### 4.4 エサやり機能
- **目的：** 錦鯉にエサを与える操作を通じて、艶の向上と錦鯉との触れ合いを楽しめるようにする。
- **入力：** エサやりの対象となる錦鯉。
- **処理：**
  - ユーザーがエサやり操作を行うと、対象の錦鯉の艶の数値を一定量上昇させる。
  - 艶の数値が上限値に達している場合、それ以上は上昇しない。
  - エサやりに合わせて、錦鯉の口の動きを大きくするアニメーションを再生する。
- **出力：** エサやりの動作と錦鯉のアニメーションを表示し、更新された艶の数値・評価を反映する。
- **エサの種類：** エサは1種類とする。
- **艶の上昇量：** エサやり1回につき一定量上昇する。具体的な上昇量は実装仕様に従う。
- **艶の上限値：** 100とする。
- **アニメーション：** 通常時も錦鯉の口を動かし、エサやり時には通常時より大きく動かす。
- **成長：** エサやりによる錦鯉のサイズ変化は発生しない。
- **水質：** 水質の管理およびエサやりによる水質の変化は扱わない。
- **制約：** 艶の数値は0〜100の範囲とする。

### 4.5 交配機能
- **目的：** 2匹の錦鯉を交配させ、新しい錦鯉を生成する。
- **画面：** SCR-02（錦鯉一覧・交配画面）。一覧・詳細機能（4.3）と同一画面とする。
- **入力：** 親となる錦鯉2匹（同画面の一覧から選択する）。
- **処理：** 選択した2匹の錦鯉のデータをもとに、交配処理を実行する。
- **出力：** 生成された錦鯉の画像と個体情報を同画面に表示する。
- **事前条件：** 交配可能な錦鯉を2匹選択していること。
- **模様の決定方法：** 交配処理の詳細仕様に従う。
- **データ管理：** 生成された錦鯉の個体情報を保存し、同画面の一覧に反映する。
- **例外処理：** 交配条件を満たさない場合は、交配を実行せず、ユーザーに通知する。

### 4.6 模様・質感の表示機能
- **目的：** 錦鯉ごとの模様や質感の違いを3Dモデル上に表現し、個体ごとの特徴を鑑賞できるようにする。
- **模様：** 錦鯉の模様を3Dモデルに反映し、個体ごとの模様の違いを表現する。模様の生成方法や交配による変化については、交配機能の仕様に従う。
- **質感：** 錦鯉ごとに艶の数値・評価を設定し、その値に応じて3Dモデルの表面の艶を変化させる。
- **表示方法：** 池画面および錦鯉一覧・交配画面に、模様と質感を反映した3Dモデルを表示する。必要に応じて、錦鯉の詳細情報として艶の数値・評価を表示する。
- **制約：** 成長や水質の変化による模様・質感の変化は扱わない。

### 4.7 品評会機能
- **目的：** 錦鯉の模様・体格・艶を評価し、品評会への参加を通じて交配やエサやりの成果を確認できるようにする。
- **入力：** 参加する品評会、参加させる錦鯉1匹。
- **処理：**
  1. 開催中の品評会一覧を表示する。
  2. ユーザーが参加する品評会を選択する。
  3. 所持している錦鯉から参加させる個体を1匹選択する。
  4. 選択した錦鯉の模様・体格・艶をもとに評価点を算出する。
  5. 評価点に基づいて順位を決定する。
  6. 品評会の結果を記録し、順位などの条件に応じた報酬を付与する。
- **出力：** 評価項目ごとの得点、合計点、順位、獲得報酬を表示する。
- **開催形式：** 開催中の品評会から参加先を選択する。開催期間外の品評会には参加できない。
- **参加条件：** 所持している錦鯉を1匹選択すること。
- **評価項目：**
  - **模様：** 交配時に決定した模様をもとに評価する。
  - **体型：** 交配時に決定した体の形状や全体のバランスをもとに評価する。成長による体型の変化は発生しない。
  - **艶：** エサやりによって上昇する艶の数値をもとに評価する。
- **評価方法：** 各評価項目の得点を算出し、合計点に基づいて順位を決定する。配点や採点基準は別途定める。
- **報酬：** 品評会の結果に応じて、池の装飾アイテムなどの報酬を付与する。報酬の種類や獲得条件は別途定める。
- **記録：** 参加した品評会、参加した錦鯉、評価点、順位、獲得報酬を記録し、後から確認できるようにする。
- **制約：** 成長や水質の管理機能は設けない。

### 4.8 池のカスタム機能
- **目的：** 池の見た目を変更し、ユーザーが好みの環境で錦鯉を鑑賞できるようにする。
- **入力：** ユーザーが選択した装飾素材やカスタム項目。
- **処理：** 選択された素材や設定を池の表示に反映する。
- **出力：** カスタマイズ後の池を表示する。
- **操作方法：** 池カスタム画面で素材を選択し、変更を反映する。
- **保存方法：** （カスタム内容を保存する仕様を記載）
- **制約：** 変更可能な項目や使用できる素材は、実装仕様に従う。

| 個体ID | 錦鯉を識別するID | 個体ごとに一意の値を設定 |

| 生成日時 | 個体が生成された日時 | 必要に応じて保存 |

| 親個体ID（1） | 1匹目の親の個体ID | 錦鯉データと紐づける |

| 子個体ID | 交配によって生成された個体のID | 錦鯉データと紐づける |
| 交配日時 | 交配を実行した日時 | 必要に応じて保存 |
| 交配結果 | 生成された個体の模様・体型などの情報 | 必要に応じて保存 |

### 5.3 品評会データ

| 項目名 | 内容 | 備考 |
|---|---|---|
| 品評会ID | 品評会を識別するID | 一意の値 |
| 品評会名 | 品評会の名称 | 画面に表示 |
| 開催期間 | 品評会の開始日時・終了日時 | 開催中かどうかの判定に使用 |
| 参加条件 | 品評会に参加するための条件 | 必要に応じて設定 |
| 評価項目 | 模様・体型・艶 | 各項目の採点基準は別途定める |

| 順位 | 品評会での順位 | 結果として保存 |
| 獲得報酬 | 参加によって獲得した報酬 | 報酬がある場合に記録 |
| 参加日時 | 品評会に参加した日時 | 必要に応じて保存 |
