## 4. シーンとクラス

```
IkeScene
  KoiSpawner             … PondCustomStore で絞った個体を放流
  PondFloorApplier       … 選んだ底テクスチャを Plane に載せる
  KoiNaturalTurn         … 視界内遊泳（ファイルは KoiRandomMove.cs）
  KoiGrowthController    … スケール。企画の成長機能ではない
  KoiRippleEmitter       … 波紋
  RippleSimulator        … 水面シミュレーション

全シーン（Menu）
  SettingsUI             … User を押して設定。言語と管理者ツールのオンオフ
  Loc                    … UI 文言（ja / en）

ShopScene
  PondCustomUI           … 泳がせる鯉・背景・浮いてるもの。pond.json に保存

HinpyokaiScene
  HinpyokaiUI            … 暫定順位・詳細・参加。Menu は既存プレハブ

KoiDetailScene
  KoiDetailUI            … 個体の名前・仮の品種/生年月日/入賞・模様点・艶点。Menu は既存
  KoiDetailGate          … 開く個体と、出品ボタンを出すかどうか

KoiScene
  KoiListUI              … 鯉一覧と左タブ（一覧 / 交配 / 作成 / 編集）。Menu は既存
  SelectManager          … パネル切替。作成・編集タブはあとから非表示にできる
  BreedingUIManager      … 親選択・交配・子の保存（ファイルは BreedingManager.cs）
  KoiEditorManager       … スライダー・カラーピッカー・保存
  KoiPhotoStudio         … サムネイル撮影
  KoiController          … PatternData → MaterialPropertyBlock
  ObjectRotator          … モデル回転
```

遷移は `SceneLoader`。`sceneAsset` に加えて `sceneName` 文字列を持つ。ビルドでは `sceneName` を使う（シーンアセット参照は Player では消える）。

## 5. データ（実装）

### 5.1 現行: KoiPatternData

`Assets/Script/KoiPatternData.cs`  
メニュー: `Create > Koi > PatternData`  
保存先: `Assets/KoiData/*.asset`

| フィールド | 型 | 意味 |
|------------|----|------|
| `koiId` | string | ランタイム保存用の個体ID。空なら保存時に発行 |
| `mainColor` | Color | 地色 |
| `sub1Color` / `sub1Scale` / `sub1Amount` / `sub1Detail` | | サブ 1（緋など） |
| `sub2Color` / `sub2Scale` / `sub2Amount` / `sub2Detail` | | サブ 2（墨など） |
| `patternSeed` | Vector3 | 模様の個体差 |
| `bellyLimit` | float | 腹の白残り |
| `photoTexture` | Texture2D | サムネイル |

個体の表示名はアセットの `name`。企画の品種・艶・親ID・体型は未所持。

### 5.2 企画項目とのギャップ

| 企画 | 現状 |
|------|------|
| 個体ID | `koiId`（JSON 保存時に GUID） |
| 品種 | なし |
| 模様データ | 上記フィールド |
| 体型データ | なし（`KoiGrowthController` は別物） |
| 艶 0〜100 | なし。シェーダーのコート／グアニンへ載せる想定 |
| 親個体ID | なし |
| 交配履歴・品評記録 | なし |

同名保存時は表示名に連番を付ける。

### 5.3 ランタイム保存（KoiSaveStore）

`Assets/Script/KoiSaveStore.cs`

交配・編集の保存は、ビルドでも残るように JSON へ書く。

| 項目 | 内容 |
|------|------|
| 場所 | `Application.persistentDataPath/KoiSaves/` |
| 個体 | `koi.json` |
| 写真 | `photos/{koiId}.png` |
| 読み込み | 初期個体 ＋ JSON のユーザー個体。`deletedKeys` に入った個体は出さない |
| 削除 | 個体詳細の削除。確認ダイアログのあと JSON から外し、初期個体も一覧に出さない |

**初期個体**
- 正本: `Assets/KoiData/*.asset`
- ビルド: `Resources/BuiltinKoiCatalog` が個体アセットを参照するので Player に載る。エディタがフォルダを同期し、ビルド直前にもコピーする

**書き込み**
- `BreedingUIManager.SaveChildKoi` と `KoiEditorManager.FinalizeSave` が `KoiSaveStore.Save` を呼ぶ
- Editor では従来どおり `Assets/KoiData` への `.asset` も残す（開発用）

一覧と池のスポーンはどちらも `KoiSaveStore.LoadAll()`。

### 5.4 シェーダー

エントリ: `Custom/URP_Koi_Pattern_Managed`  
分割: `Assets/Shader/KoiCommon.hlsl` / `KoiPattern.hlsl` / `KoiLighting.hlsl`

`KoiController.ApplyDNA()` が載せる値:

| シェーダー | データ |
|------------|--------|
| `_MainColor` | `mainColor` |
| `_SubColor*` / `_Sub*Scale` / `_Sub*Amount` / `_Sub*Detail` | サブ色 |
| `_Seed` | `patternSeed` |
| `_BellyLimit` | `bellyLimit` |

光学（コート、グアニン）はマテリアル側。艶パラメータ接続はこれから。

鱗の UV マス目による凹凸は入れない。テクスチャに描いた鱗を使う。

## 6. 現行の動き

### 6.1 交配（BreedingUIManager）

1. 親スロットからリストを開く  
2. `KoiSaveStore.LoadAll()` で一覧。写真が無ければスタジオ撮影  
3. 両親が揃うと交配可能  
4. 子プレビューのあと名前を付けて `KoiSaveStore.Save`（空なら「名無しの錦鯉」）

**遺伝（現行）**

- 色と `patternSeed` のベースは親から 50% で一方を選ぶ  
- シードに X/Y 方向 -5〜+5 のずれ（Z は 0）  
- 量・スケール・ディテールは `blendRate` 0.3〜0.7 で補間  
- `bellyLimit` は平均  
- 15% でサブ量を 0 にして単色化  

これが企画 4.2 の「模様の決まり方」の現行実装である。

### 6.2 作成・編集（開発用）

Single / Dual / Triple。スライダーとカラーピッカー。JSON 保存。Editor では `.asset` も書く。

### 6.3 池

Start 時に `PondCustomStore.FilterSwimming(KoiSaveStore.LoadAll())` してスポーン。カスタムで選ぶまで所持分を全部出す。視界の 70% 内側。`Koi` タグ同士で減速。`PondFloorApplier` が選んだ底テクスチャを載せる。

泳いでいる個体のクリック／選択は未実装。企画 4.1 のとおり、選択したら交配の親・エサ・品評へ渡す。

### 6.4 エサやり（未実装）

企画 4.3。池で選んだ個体の艶を上げ、`KoiSaveStore` に書き戻す。口アニメを大きくする。サイズは変えない。艶はシェーダーのコート／グアニンへ載せる。

### 6.5 池カスタム（PondCustomUI）

`ShopScene`。枠は既存の `KoiPanel` / `FloorPanel`。タイトルとナビは既存の `Menu` プレハブ。右へ進むと 2 枚ずつ見せる。

- 1 枚目：左が泳がせる鯉、右が背景（床）
- 2 枚目：左が背景（床）、右が浮いてるもの
- 鯉：所持個体。タップで池に出す／出さない。`詳細` で拡大
- 背景：`Assets/UIimage/floor` の画像から 1 つ
- 浮いてるもの：`Assets/UIimage/float` のセット、またはなし
- 保存：`persistentDataPath/KoiSaves/pond.json`

新しい PNG を `Assets/UIimage/floor` に入れると、エディタが `Resources/PondFloorCatalog` へ足す。浮かべるセットは `PondFloatCatalog`。池の Plane には選んだ床テクスチャを載せる。

### 6.6 品評会（HinpyokaiUI）

`HinpyokaiScene`。タイトル・総合タブ・順位一覧・詳細・参加ボタン。ナビは既存の `Menu`。

- 所持個体を模様・体型・艶で仮採点して暫定順位を出す。一覧はスクロールする
- 行をタップすると右の詳細（写真・合計・内訳）
- 艶はエサ未実装のため 70 を仮置き。配点と報酬はこれから
- 「品評会に参加する」は一覧へ行き、個体詳細の出品ボタンで出す鯉を決める。順位に出るのは出品した個体だけ
- 品種・生まれた日・入賞回数の実データはまだ無いのでラベルのみ

### 6.7 水面

`KoiPond`。`RippleSimulator` と `KoiRippleEmitter`。コースティクスは OpenGameArt（CC0）、HDRI は Poly Haven Mossy Forest（CC0）。

### 6.8 設定と文言

メニュー左上の `User`（白い波）を押すと設定。`SettingsUI` が実行時にダイアログを乗せる。枠の見た目は触らない。

- 言語：日本語 / English。`Loc` のキーで製品 UI を差し替える。保存は `persistentDataPath/KoiSaves/settings.json`
- 管理者ツール：オン／オフだけ覚える。中身はこれから
- 個体名や床画像の名前は訳さない

## 7. 制約

- 初期個体は `BuiltinKoiCatalog` 経由。交配した個体は JSON で残る。  
- ファイル名とクラス名のずれ: `BreedingManager.cs` → `BreedingUIManager`、`KoiRandomMove.cs` → `KoiNaturalTurn`。  
- `KoiNaturalTurn` は毎フレーム `FindGameObjectsWithTag("Koi")`。  
- 縁が黒く見える問題: 横向き面で光が消える計算。コートの F 上限・影の下限・反射の上向き補正を入れている（`feature/koi-shader`）。

## 9. 実装のこれから（優先順）

企画の体験に必要な順。成長ループは載せない。

1. 池で泳いでいる個体を選ぶ（交配の親 / エサ / 品評へ渡す）  
2. 艶 0〜100 とエサやり（口アニメ、サイズ不変、JSON へ保存）  
3. SCR-02 を一覧＋交配に揃える  
4. 親個体ID・生成日時。体型データの中身  
5. 品評の配点を本番値へ。参加個体の選択と報酬  
6. 品評報酬とカスタム素材の接続  
7. ビルド確認（初期個体はカタログ同期済み）
