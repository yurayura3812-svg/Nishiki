# 錦鯉の光沢の仕組み（やさしい解説）

錦鯉の見た目は、大きく分けて **「色」** と **「光沢（照り）」** の2つでできています。
CGで再現するときも、この2つを分けて考えるのが近道です。

---

## 1. 鯉の皮膚は「層」になっている

錦鯉の体表は、上から順に何層も重なっています。おおまかには次のようなイメージです。

```
      光 ↓
 ┌──────────────────────┐
 │ 粘液・表皮（透明、薄いツヤ）   │ ← 濡れたようなツヤ
 ├──────────────────────┤
 │ 鱗（ほぼ透明）               │
 ├──────────────────────┤
 │ 色素の層（紅・墨・黄など）     │ ← 「色」を決める
 ├──────────────────────┤
 │ 反射の層（グアニンの薄い板）   │ ← 「照り・銀色の輝き」を決める
 └──────────────────────┘
```

- **色素の層**が、紅白の「緋」や大正三色の「墨」の色を決めます。
- **反射の層**が、下から光を跳ね返して、色を明るく見せたり、銀色・金色に光らせたりします。

白い部分が真っ白に見えるのも、この反射の層が光をよく返しているからです。

---

## 2. 「色」の正体：色素

| 見た目の色 | 主な色素 | ひとこと |
| --- | --- | --- |
| 紅（赤） | カロテノイド（アスタキサンチンなど） | 餌から取り込む。だから「色揚げ」の餌がある |
| 黄 | カロテノイド（ゼアキサンチンなど） | 黄色い品種は餌の色素をそのまま貯める |
| 墨（黒） | メラニン | 錦鯉は背景が明るくても墨が薄くなりにくい |
| 白 | 色素がほぼない | 下の反射層の白さがそのまま見える |

つまり色素は **「絵の具」** のようなものです。

---

## 3. 「光沢」の正体：グアニンの薄い板の重なり

ここが錦鯉らしさの核心です。

鱗や皮膚の中には、**グアニン**という物質でできた、とても薄い透明な板（厚さ0.00005〜0.0001mmほど）がたくさんあります。
この板と、細胞の中身（水っぽい部分）が、**交互に何十層も重なって**います。

```
 光 ↓   ↗ ↗ ↗ ↗（それぞれの層で少しずつ反射）
 ━━━━━━━  グアニンの板
 ～～～～～  細胞の中身
 ━━━━━━━  グアニンの板
 ～～～～～  細胞の中身
 ━━━━━━━  グアニンの板
   ……（これが何層も続く）
```

光は層の境目に当たるたびに、少しずつ反射します。
その反射がたくさん重なると、**鏡のような強い輝き**になります。

身近な例でいうと、

- **シャボン玉**：薄い膜1枚で虹色に光る
- **真珠**：薄い層がたくさん重なって、柔らかく光る
- **錦鯉の鱗**：薄い板が重なって、銀色〜金色にギラッと光る

と、どれも同じ仲間の仕組みです。

### 層の厚さがそろっていないから「銀色」になる

層の厚さがきっちりそろっていると、特定の色だけが強く反射して、虹色やメタリックな青になります（熱帯魚のネオンテトラなど）。
錦鯉の板は厚さや間隔に**ほどよいばらつき**があります。そのため、いろいろな色の光がまんべんなく反射して、混ざって **「銀色（白っぽい輝き）」** に見えます。

## 4. よく光る鯉と、そうでない鯉の違い

研究（Gur ら 2014）では、よく光る品種と普通の品種の鱗を比べています。

| | よく光る品種（銀鱗・プラチナ系） | 普通の品種 |
| --- | --- | --- |
| 反射する細胞の数 | 多い | 少なめ |
| 板の重なりの数 | 多い | 少なめ |
| 板の向き | 鱗の表面と**ほぼ平行**にそろう | 約30°**斜め**に傾いている |

板が表面と平行にそろっていると、正面から来た光をまっすぐ返すので、**強くギラッと光ります**。
斜めだと光がよそへ逃げるので、光り方がおだやかになります。

## 5. CGで再現するときの考え方

上の仕組みを、CGの素材（マテリアル）に置き換えると次のようになります。

| 本物の鯉 | CGでやること |
| --- | --- |
| 色素の層（紅・墨・白） | **ベースカラー**のテクスチャ。実物を測った色を使うと正確 |
| 反射の層（グアニンの板） | **多層膜（薄膜干渉）の反射**を表現できるシェーダーを使う |
| 板の向き・ばらつき | 反射の強さや広がり（ラフネス）を、鱗ごとに少しずつ変える |
| 粘液・表皮のツヤ | 一番上に、薄い**コート層（クリアコート）**を重ねる |
| 鱗の形 | 鱗の模様の**法線マップ**で、1枚ずつの凹凸と光り方の違いを出す |

ポイントは次の2つです。

- **「色」と「光沢」を別々の層として作る**
- 普通の「ツヤ」設定だけで済ませず、**重なった薄い膜の反射**を意識する

これが、錦鯉らしい「照り」をCGで出すための基本の考え方です。

## 用語ミニ辞典

- **グアニン**：魚の体の中で作られる物質。結晶になると光をよく反射する。化粧品のパール成分にも使われる。
- **虹色素胞（こうしきそほう）**：グアニンの板を作り、ため込んでいる細胞。
- **薄膜干渉（はくまくかんしょう）**：薄い膜の表と裏で反射した光が重なり、色や強さが変わる現象。
- **多層膜反射**：薄い膜がたくさん重なって、強い反射を生む仕組み。錦鯉の光沢はこれ。
- **シェーダー**：CGで「この素材はこう光る」を計算するプログラム。
- **法線マップ**：表面の細かい凹凸を、形を変えずに光の当たり方だけで表現するテクスチャ。
