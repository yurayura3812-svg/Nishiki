# 錦鯉シェーダーの作り方（Unity URP / HLSL）

「錦鯉の光沢の仕組み.md」で説明した皮膚の層構造を、URPのHLSLシェーダーでどう組み立てるかをまとめたメモです。
コードそのものではなく、**組み立て方の方針**を書いています。

---

## 全体の考え方

本物の鯉の「層」を、そのままシェーダーの計算の層にします。

```
最終色 = 粘液のツヤ（クリアコート）
       + (1 - 粘液の反射分) × [ 色素の拡散色  +  グアニン反射 × 色素の色フィルター ]
```

| 本物の層 | シェーダーでの扱い |
| --- | --- |
| 粘液・表皮 | クリアコートの鏡面反射 |
| 色素の層（紅・墨・白） | 拡散色＋反射光の色フィルター |
| 反射の層（グアニンの板） | 専用の法線とLUTで計算する鏡面反射 |
| 鱗の形 | 法線マップ＋鱗ごとのランダム値 |

URP標準の `UniversalFragmentPBR` をそのまま使うと、「色素の下にある反射層」が表現できません。
そこで、**ライティング計算を自前で書く**のが基本方針です。

---

## 1. 用意するテクスチャ・プロパティ

| 名前 | 役割 |
| --- | --- |
| `_BaseMap` | 模様の色（紅・墨・白）。色素の色そのもの |
| `_ScaleNormal` | 鱗1枚ずつの凹凸を表す法線マップ |
| `_ScaleID` | 鱗ごとにランダムな値（0〜1）が入ったマップ。鱗ごとに光り方を変えるのに使う |
| `_GinrinMask` | 光る鱗の位置（銀鱗・光り物用）。普通の鯉なら弱め |
| `_ReflectLUT` | グアニン多層膜の反射率を、角度ごとに事前計算したテクスチャ |
| `_PlateTilt` | グアニン板の傾き。光る品種は0°付近、普通は約30° |
| `_GuanineRoughness` | 反射層のラフネス（低め） |
| `_CoatF0` / `_CoatRoughness` | 粘液層の反射率とラフネス |

---

## 2. URPの骨組み

- Passは `UniversalForward` を1つ用意します（影を使うなら `ShadowCaster`、深度を使うなら `DepthOnly` も）。
- `Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl` をincludeします。
- メインライトは `GetMainLight()` で取得します（影は `TransformWorldToShadowCoord` と組み合わせます）。
- 追加ライトは `GetAdditionalLightsCount()` と `GetAdditionalLight()` のループで取得します。
- 環境光は `SampleSH()` で、映り込みは `GlossyEnvironmentReflection()`（Reflection Probe）で取得します。

各ライトに対して、下の3〜5の計算を自前の関数（例：`KoiLighting(...)`）で行い、足し合わせます。

---

## 3. グアニン反射（錦鯉らしさの核心）

### 3-1. 板の向きを「別の法線」で持つ

グアニンの板は、鱗の表面と完全に同じ向きではありません。

1. `_ScaleNormal` から鱗の法線を作る
2. `_ScaleID` のランダム値で、傾ける方向を鱗ごとに決める
3. `_PlateTilt` の角度だけ法線を傾ける → **反射層専用の法線**

この法線で鏡面反射（GGXなど）を計算すると、魚が動いたときに**鱗ごとにキラッと光る**ようになります。
**見た目に一番効くのがここ**です。

- ラフネスは低め（鋭いハイライト）にします。
- 光る品種（銀鱗・プラチナ系）は、傾きを小さく、反射を強くします。
- 普通の品種は、傾きを大きめにして、反射を弱めにします。

### 3-2. 反射率はLUTで持つ

本物の反射は「薄膜が何十層も重なったもの」です。毎ピクセル計算すると重いので、次のように分けます。

- **事前計算（C#、エディタ拡張など）**
  - 転送行列法で多層膜の反射率を計算します。
  - 屈折率の目安は、グアニン約1.83、細胞質（水）約1.33です。
  - 層の厚さに乱数でばらつきを入れて平均します。
  - 横軸 = cosθ、縦軸 = ばらつき量のRGBテクスチャに焼きます。
- **シェーダー**
  - `_ReflectLUT` を `(cosθ, ばらつき)` で引くだけにします。

錦鯉は層の厚さにばらつきがあるので、反射は**ほぼ白（銀色）で、斜めから見るとやや色づく**程度になります。

最初はLUTの代わりに、**白っぽいフレネル反射（Schlick近似、F0を高め）で仮置き**しても大丈夫です。

---

## 4. 色素をフィルターとして掛ける（重要）

グアニン層は色素層の**下**にあります。
そのため、反射光は色素を往復で2回通ってから目に届きます。

```hlsl
float3 pigmentTint = baseColor * baseColor;   // 往復で2回通過
float3 guanine     = guanineSpec * pigmentTint * ginrinMask;
```

これだけで、見た目が次のように自然に分かれます。

| 部位 | 見え方 |
| --- | --- |
| 白地 | 銀色に光る |
| 緋（赤） | 赤く照る |
| 墨（黒） | ほとんど光らない（黒が光を吸う） |

錦鯉らしい「緋の照り」は、この掛け算から出ます。
2乗だと強すぎる場合は、`pow(baseColor, _TintPower)` のように調整用パラメータにしておくと便利です。

---

## 5. 粘液のクリアコート

一番上に、薄い水の膜のような反射を足します。

- GGXで計算し、F0は0.02〜0.04程度、ラフネスはやや低めにします。
- この層で反射した分（フレネル `F_coat`）だけ、下の層を暗くします。

```hlsl
float3 color = coatSpec
             + (1.0 - F_coat) * (diffuse + guanine);
```

---

## 6. 作る順番のおすすめ

1. `_BaseMap` の拡散色＋メインライトだけを出す
2. クリアコートを足す（濡れた感じが出る）
3. グアニン反射を「白いフレネル反射」で仮置きし、色素フィルターを掛ける
4. 反射層専用の法線と `_ScaleID` で、鱗ごとのキラッを出す ← **ここで一気に錦鯉らしくなる**
5. 反射率をLUTに置き換えて、角度による色づきを入れる
6. 追加ライトと環境反射（Reflection Probe）に対応させる

4までで、見た目の8割は出ます。

---

## 7. 調整のコツ

| 気になる点 | 調整するところ |
| --- | --- |
| 全体がプラスチックっぽい | クリアコートを弱め、グアニン反射を強めにする |
| 光り方が均一すぎる | `_ScaleID` によるばらつきと `_PlateTilt` を大きくする |
| 墨が光ってしまう | 色素フィルター（`pigmentTint`）が掛かっているか確認する |
| 白地が灰色っぽい | グアニン反射の強さと、環境反射の明るさを上げる |
| 水中で見え方が違う | 水中ではフレネルの屈折率比が変わる。水中用にF0を下げる |
